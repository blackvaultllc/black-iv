WHAT IS A FILE? COMPUTER BASICS 101

A file is a box with a name. Once you see that, computers get easier.

Daily article — November 5, 2026  |  Silent Security Vault — Domenick Arlon Hall, Mobile, AL

A file is one thing saved on a computer — a photo, a letter, a song. Every file has a name and a place where it lives. Folders are just boxes that hold files. Once you see that, the whole computer gets easier.

What you need to know

  • A file has a name and a type. The ending tells you the type: .jpg is a photo, .pdf is a document. The name tells you what it is.
  • Folders are boxes. Put photos in the Photos folder, letters in Documents. A folder inside a folder is a smaller box inside a bigger one.
  • Save means put it somewhere. When you save, the computer asks where. Pick a folder you will remember, and give the file a clear name.
  • Search finds lost files. If you forget where a file is, search for its name. You do not need to remember the folder.
  • Deleting is not always forever. Deleted files often sit in the trash first. Empty the trash only when you are sure.

What to do next

Today: open your Documents folder and look at what is there. Rename one file with a clear name. That is the whole lesson.
